About Screw Game

Small puzzles, carefully considered

screw.games is an independent browser game project exploring the screw-puzzle family. Our collection includes Screw Puzzle, Screw Sort, Screw Jam, Screw Box, Screw 3D and Screw Escape. Each mode has a warm-up and a more demanding second level, with generated layouts checked by a rule-based solver.

What we build

We build the game logic, interface, procedural board art and Screw Game identity for this site. We are not an official site for another screw-game publisher. We do not imply affiliation with games or platforms that use similar genre terms.

A fair kind of challenge

You can start playing without an account. Retry keeps the same arrangement, so an unsuccessful attempt can teach you something. Cosmetic rewards are intended to mark progress without making another player’s puzzle easier. Future modes are only listed as playable after their actual rules are available.

Development and feedback

This is the first Web release. Device compatibility, difficulty and sound are refined through testing and player feedback. If a control is unclear or you encounter a broken layout, send the mode, seed and a description to marlonqiu2027@gmail.com. Please do not include private account tokens or passwords.
