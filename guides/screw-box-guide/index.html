Screw Box: a practical strategy guide

A color is only useful when there is a box ready for it. Screw Box turns the familiar act of removing a screw into an order-packing puzzle: finish the containers in front of you while keeping enough temporary room to reach the next useful color.

Open the practice board →

1. Plan a box completion

Count remaining sockets before choosing a panel. An order needing one more screw can release a new color and absorb waiting screws. Compare that benefit with exposing a lower panel.

2. Spend space deliberately

Name the screw or panel an unmatched pickup will unlock. If you cannot identify its purpose, inspect another stack before occupying a temporary slot.

3. Review the same seed

Retry after a loss and alter the first speculative pickup. A new layout hides whether you understood the old decision; the same layout makes the difference observable.

Try this exercise

Find a box with two occupied sockets. Before collecting its third screw, list the colors waiting below it. Make the move and observe whether the new order absorbs any of them. Retry the same seed and compare an opening that spends a temporary slot first. Which sequence leaves more room when the next layer appears?

A useful review after a loss

Keep the layout unchanged for one more attempt. Identify the first decision whose purpose you could not explain, then change that decision and observe the consequence. Do not compare only the move count: compare accessible choices and the remaining objective. New layout is useful for variety, while Retry is useful for learning a particular dependency. A shared seed lets somebody else investigate the same starting arrangement without copying your saved moves.

What a helper can and cannot establish

A Hint is offered only after finding a complete continuation within its search budget. An unsuccessful search does not prove that every route is blocked. Undo restores the preceding action once; it does not erase an arbitrary earlier mistake. Read the Rescue explanation for this mode before confirming, because collection games add space while Escape rewinds a support. Practice helpers are separate from purchased inventory in these new modes.

Common questions

Is Screw Box the same as Screw Jam?+

No. Box accepts colors requested by its open orders. Jam clears any completed trio in a shared buffer. Three waiting screws do not clear in Box unless their order is available.

How many levels are there?+

Two: a compact teaching level and a longer expert level. Both are available without completing a progression map.

What happens to an unmatched screw?+

It waits in a temporary slot. When a matching order opens, waiting screws can enter it automatically.

Can I tap a covered screw?+

No. Clear every screw on the exposed panel in that stack to reach the next panel.

When do I lose?+

The run ends if the temporary row fills after completed boxes and waiting matches have settled.
